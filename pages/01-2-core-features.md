## 01-2. 핵심 기능 소개

## 1. 음성 입력

`sounddevice`를 사용해 마이크로 음성을 녹음합니다. 음성 데이터는 WAV 형식으로 저장되며, `record_audio_to_wav()` 함수가 이를 담당합니다.

## 2. 음성 인식(STT)

`call_transcribe()`는 OpenAI의 오디오 변환 API를 호출합니다. 녹음된 파일을 읽어 텍스트로 변환하고, 사용자가 말한 내용을 분석 가능한 문자열로 만듭니다.

## 3. 사투리 및 방언 정규화

대다수의 학생이 표준어가 아닌 억양이나 사투리를 사용하므로, `normalize_dialect()` 함수를 통해 경상도 표현을 자연스러운 표준어로 바꾸는 작업을 합니다.

## 4. 수학 용어 사전 검색

`math_json/math.json`에서 수학 용어와 뜻, 예시를 불러옵니다. 사용자의 질문이 특정 수학 용어와 일치하면 바로 의미를 설명해 줍니다.

## 5. AI 대체 응답

매칭되지 않는 용어나 설명이 부족한 경우 `call_chatgpt()`를 호출해 GPT 응답을 생성합니다. 이 기능은 수학 용어집만으로 부족할 때 보완 역할을 합니다.

## 6. TTS 음성 출력

최종 답변은 `call_tts()`를 통해 음성 파일로 변환되고, `play_mp3()`로 재생됩니다. 이를 통해 시각적인 글자보다 음성으로 이해하는 방식이 가능해집니다.

## 7. MCP 기반 파일 접근

`MCPServerStdio`를 사용해 파일 시스템에 접근합니다. 이 기능은 프로젝트 내부 파일을 AI가 읽고 이해하는 데 활용됩니다.
