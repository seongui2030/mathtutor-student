# 06-1. 규칙 기반 정리

`normalize_dialect()`는 우선 단순 규칙 기반으로 반복되는 사투리 표현을 정리합니다.

예시 규칙:

```python
rules = {
    "하지 마이소": "하지 마세요",
    "하지 마소": "하지 마세요",
    "묵어라": "먹어라",
    "안 하이소": "안 하세요",
    "마이": "많이",
}
```

이 규칙은 고정된 문장 패턴을 기준으로 처리하므로, 입력이 자주 등장하는 표현일수록 정확하게 변환됩니다.

정규화의 첫 단계는 이 규칙 집합을 적용하는 것입니다.
