## 02. 설치 및 준비

프로젝트를 실행하기 전에 필요한 도구와 환경을 준비해야 합니다.

핵심 준비 요소는 다음과 같습니다.

- Python 3.12
- Node.js와 npm
- Git
- VS Code
- 마이크 장치
- OpenAI API Key

초기 설치 절차는 README에 정리되어 있으며, 핵심 흐름은 다음과 같습니다.

1. 저장소를 클론한다.
2. 가상환경을 생성한다.
3. 의존성을 설치한다.
4. .env 파일을 준비한다.
5. 프로젝트를 실행한다.

이 문서에서는 실제 필요한 요소와 설치 가이드를 정리한다.
