## 12-2. 데이터베이스 구조

수학 데이터는 `math_json/math.json` 안에 배열 형태로 저장됩니다.

대표 구조는 다음과 같습니다.

```json
{
  "data": [
    {
      "terms": [
        {
          "word": "제곱",
          "subject_meaning": "어떤 수를 자기 자신으로 몇 번 곱한 값",
          "example": "2의 제곱은 4입니다."
        }
      ]
    }
  ]
}
```

이 구조를 통해 단어, 의미, 예시를 함께 관리할 수 있어 AI 응답 생성과 교육용 설명에 유리합니다.
