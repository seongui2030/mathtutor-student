
프로젝트는 실행 중 다양한 문제를 마주칠 수 있습니다. 특히 `npx`, `OPENAI_API_KEY`, 마이크, 그리고 모듈 의존성 문제가 대표적입니다. 이 단계는 전체 프로그램 흐름이 정상적으로 동작하지 않을 때, 문제 원인과 해결 경로를 정리하는 문서입니다.

실행 흐름의 관점에서 보면, 오류는 보통 다음 단계에서 발생합니다.

1. MCP 서버 준비 단계에서 `npx` 문제가 발생한다.
2. API 키 설정이 잘못되어 OpenAI 호출이 실패한다.
3. 마이크 접근 권한 또는 장치 문제로 녹음이 되지 않는다.
4. Python 의존성이 설치되지 않아 모듈 import 오류가 발생한다.

이 문서에서는 각 문제별 원인과 해결 방법을 정리하며, 실행 전점검과 예외 대응을 함께 설명합니다.

`11-1`부터 `11-4`는 각각 대표적인 오류 유형을 다루고 있습니다.
