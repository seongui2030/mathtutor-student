##07-1. 수학 사전 데이터

`math_json/math.json`은 수학 질문을 인식하기 위한 핵심 데이터 파일입니다.

이 파일에는 수학 관련 표현이 저장되어 있으며, 입력 문자열을 이 사전과 비교해 패턴을 찾습니다.

예시 형태:

```json
{
  "더하기": "plus",
  "빼기": "minus",
  "곱하기": "multiply",
  "나누기": "divide",
  "제곱": "square"
}
```

이 파일을 기반으로 입력 문장이 어떤 수학식으로 해석될 수 있는지 파악하고, 필요한 경우 `chatgpt_conn.py`를 통해 설명을 생성합니다.
