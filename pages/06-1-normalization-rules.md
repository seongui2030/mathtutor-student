
정규화 단계는 말하기 문맥에 따라 달라지는 표현을 표준화하는 전처리 과정입니다. 이 단계는 사용자 발화가 표준어가 아니거나 발음이 불분명할 때, 이후 수학 용어 매칭과 답변 생성이 안정적으로 동작하도록 문장을 정리하는 역할을 합니다.

`normalize_dialect()`는 우선 단순 규칙 기반으로 반복되는 사투리 표현을 정리합니다. 고정된 패턴을 기준으로 문장을 바꾸는 방식이기 때문에, 자주 등장하는 표현일수록 정확하게 변환됩니다.

예시 규칙:

```python
rules = {
    "하지 마이소": "하지 마세요",
    "하지 마소": "하지 마세요",
    "묵어라": "먹어라",
    "안 하이소": "안 하세요",
    "마이": "많이",
}
```

또한 숫자나 수학 표현도 다음처럼 규칙을 적용할 수 있습니다.

- '아마' → '암'
- '이' → '2'
- '삼' → '3'
- '사' → '4'

이 규칙들은 단순한 문자 치환이 아니라, 수학 용어 또는 계산 표현을 실제 형식으로 변환하는 전처리입니다. 사용자 입력이 조금 어눌하거나 발음이 불분명해도, 숫자와 용어를 올바르게 인식할 가능성이 높아집니다.

즉, 정규화의 첫 단계는 이 규칙 집합을 적용하는 것입니다. 이 과정을 거치면 이후에는 `math_json/math.json`에서 정확한 용어를 찾거나, 질문을 이해하고 응답을 생성하는 데 필요한 입력 품질이 훨씬 높아집니다.
