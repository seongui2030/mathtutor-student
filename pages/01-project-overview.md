# 01. 프로젝트 소개

이 프로젝트는 마이크로 녹음한 음성을 받아 수학 용어를 질문하고, AI가 뜻을 설명해 주는 음성 기반 수학 도우미입니다.

핵심 목표는 다음과 같습니다.

- 고등학생이 한자어 수학 용어를 이해하는 데 어려움을 겪는 문제를 완화한다.
- 음성으로 질문하면 답을 직접 들을 수 있도록 한다.
- 수학 용어집인 math.json을 활용해 빠르게 정답을 찾는다.
- 매치되지 않는 용어는 GPT 기반 응답으로 보완한다.
- 최종 답변을 TTS로 변환해 음성으로 재생한다.

전체 흐름은 다음과 같습니다.

1. 마이크로 음성 녹음
2. STT로 텍스트 변환
3. 경상도 사투리 정규화
4. math.json에서 수학 용어 매칭
5. 응답 생성
6. TTS 변환
7. MP3 음성 재생

이 흐름은 `total_mic_speak_mcp.py`의 `main()` 함수에서 제어됩니다.
