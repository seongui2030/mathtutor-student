
규칙 기반 정리 뒤에는 `call_chatgpt()`를 이용한 LLM 보정이 선택적으로 실행됩니다.

```python
if use_llm:
    prompt = (
        "다음 문장은 경상도(영남) 사투리 표현을 포함할 수 있습니다.\n"
        "자연스러운 표준 한국어(평서문)로 변환해 주세요. 출력은 변환된 문장만 하세요.\n\n"
        f"입력: {s}"
    )
    refined = call_chatgpt(prompt)
```

이 단계는 규칙으로 다루기 어려운 문장까지 자연스럽게 정제합니다. 예를 들어 문맥에 따라 의미가 달라지는 표현을 표준 문장으로 바꾸는 역할을 합니다.

결과적으로 이후 수학 단어 판별 단계에서 더 안정적인 입력을 사용할 수 있습니다.
