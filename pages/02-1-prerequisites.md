## 02-1. 사전 요구사항

이 프로젝트는 Python 기반으로 동작하므로 기본 개발 환경이 필요합니다.

- Python 3.12

Python 3.12 이상을 권장합니다. 이 프로젝트는 `venv` 기반으로 실행할 수 있습니다.

```bash
python --version
```

- Node.js와 npm

MCP 파일 시스템 서버를 실행하기 위해 Node.js와 npm이 필요합니다. 특히 `npx` 명령어가 사용 가능해야 합니다.

```bash
npx --version
```

- Git

소스 저장소를 복제하고 버전 관리를 하기 위해 Git이 필요합니다.

```bash
git version
```

- 마이크

음성 입력을 받아야 하므로 PC의 마이크가 연결되어 있어야 합니다. Windows에서는 마이크 접근 권한을 허용해야 합니다.

- VS Code

본 프로젝트는 VS Code에서 실행하는 것을 권장합니다. 개발 편의성과 디버깅에 유리합니다.

- .env 파일 설정
- OpenAI API Key 발급
- 로컬 가상환경 활성화
