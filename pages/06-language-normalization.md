
STT로 추출된 텍스트는 곧바로 `normalize_dialect()`로 전달됩니다. 이 단계는 사용자 발화가 표준어가 아니거나, 사투리와 비슷한 표현으로 들릴 때 이를 이해 가능한 형태로 바꾸는 전처리 과정입니다.

사용자의 음성은 표준어가 아닐 수 있습니다. 특히 경상도 억양, 사투리, 발음상 비슷한 표현은 텍스트가 잘못 인식되거나 의미가 흐려질 수 있습니다. 이 프로젝트는 `normalize_dialect()`를 사용해 문장을 표준어에 가깝게 정리합니다.

```python
def normalize_dialect(text):
    text = text.replace('아마', '암')
    text = text.replace('이', '2')
    text = text.replace('삼', '3')
    text = text.replace('사', '4')
    return text
```

이 함수는 발음이 비슷하거나 표준어와 다르게 말해도, 수학 질문을 올바르게 인식할 수 있도록 텍스트를 정리합니다. 예를 들어 발음상 혼동이 있는 숫자 표현을 정규화하여 실제 수학 문맥에 맞는 형태로 바꾸는 역할을 수행합니다.

핵심 동작은 다음과 같습니다.

- 자주 사용되는 사투리 표현 변환
- 문맥상 애매한 표현 수정
- 수학 용어와 숫자 인식의 정확도 향상
- 이후 `math_json/math.json` 매칭을 안정적으로 만들기 위한 전처리

예를 들어 “묵어라”, “안 하이소” 같은 표현을 표준 한국어로 바꿔 문장을 더 이해하기 쉽게 만들고, 숫자 표현의 혼동도 줄이는 방식으로 동작합니다.

이 단계는 단순한 문장 정리가 아니라, 이후 용어 검색, 의미 해석, AI 응답 생성의 정확도를 높이는 핵심 준비 단계입니다. 정규화가 잘 되어 있어야 수학 용어 사전 매칭이 안정적으로 이루어집니다.
